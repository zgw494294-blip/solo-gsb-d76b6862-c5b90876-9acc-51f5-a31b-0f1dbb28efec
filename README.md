# 装配尺寸链校验台

本地 Web 应用：录入基准点与带上下限的测量约束，检查尺寸链能否同时成立；矛盾时给出一条**负权闭环**证据；一致时查询任意两点间隙，给出由**全部约束精确推得的最紧上下界**，并按目标合格区间判为**合格 / 待复核 / 超差**。还可对一致清单做**测量清单精简**：删去不影响任何点对推断的冗余测量。对矛盾清单可做**测量容差预算**：按每条测量的步长统一放宽区间，求使整张清单首次一致的最小预算 k，并给出负环证据与调整后区间。另有**名义坐标拟合**：为每个基准点给定名义坐标，在满足全部测量的整数坐标方案中先最小化最大绝对偏差，再取字典序最小解。还可计算**补测读数窗口**：拟在两个不同基准点间补一条精确测量 [r, r]，在 ±10⁹ 的整数范围内求出全部“加入后清单仍一致、目标点对最紧间隙界有界并完全落入合格区间”的读数，输出为若干不可再扩展、互不相邻的整数闭区间。另提供**垫片组合选配**：录入 1～10 个带方向（+1/−1）的有序安装位，每位提供若干厚度/成本选项，每位恰选一项，其有符号厚度之和只把目标点对的有界最紧区间整体平移（不改原测量），在“平移后整个区间落入合格区间”的组合中先取总成本最低、并列时取选项序号向量字典序最小者。另支持**尺寸链改动影响**：把当前基准点与测量清单保存为独立基线，与后续编辑稿逐有序点对比较最紧上下界与无界状态，仅报告发生变化的点对并判定收紧 / 放宽 / 混合 / 变为有界 / 变为无界。另提供**矛盾测量最小撤回**：把每条测量标记为可撤回或锁定（至多 16 条可撤回），矛盾时只允许删除可撤回测量，求使剩余清单一致的**最少删除条数**（并列时按原录入顺序取删除序号列表字典序最小者），预览确认后才应用删除；锁定测量自身矛盾时返回不可修复及锁定部分的负环。另提供**测量复核排程**：从当前清单选取 1～16 条测量，为每条设置复核耗时、独立不合格概率（‰）与必须先复核的测量编号（依赖只能引用所选测量，成环报错）；复核遇首条不合格即停止，求满足依赖且**预期总耗时最小**的完整顺序（并列时按原录入位置的序号向量取字典序最小者），以**精确分数**返回每步执行概率与预期总耗时。另提供**目标间隙精度归因**：选取目标点对与 1～10 条待评估测量（未选测量固定为底座），对底座加每个待评估子集 S 求目标间隙最紧区间宽度 W(S)，按 **Shapley 权重** |S|!(n−|S|−1)!/n! 把宽度缩减 W(S)−W(S∪{i}) 分摊给各测量，以**既约分数**返回各测量贡献（不枚举排列），按贡献降序排名、并列按原录入顺序；贡献之和恰等于底座与全量的宽度差；底座不能给出有界最紧区间时提示不可归因。最后提供**测量缺失合格概率**：页面选择目标点对、整数合格区间及 1～12 条可能缺失的测量，为每条填写独立缺失概率（0～1000‰，未选测量始终有效，0‰/1000‰ 按确定事件处理）；完整清单矛盾时只返回负环，否则对每种缺失组合移除对应测量、增量重算目标间隙最紧界，仅在目标有界且整个区间落入合格区间时计为通过，按组合概率精确求和，以**既约分数**返回通过与未通过概率（利用子集间增量更新，不为每种组合重跑全点最短路）。另提供**极值共现工况**：按顺序录入 1～10 个目标，每项为两个不同基准点构成的有序间隙及其最紧下界或最紧上界（同一有序点对、同一界别不得重复）；对完整清单求各目标的最紧整数界，把达到该界作为等式条件叠加到原测量上，找出能由同一组坐标同时达到极值的目标数最多的子集（并列时取输入序号列表字典序最小者），返回各目标界值、入选与未入选目标，以及满足原测量和入选等式的一组整数坐标（每个原始连通分量以最早录入的基准点为零点）；目标界无界时报明目标序号、不生成工况，原清单矛盾时只返回负环。

- 后端：Python 3.11 + FastAPI（差分约束系统，Bellman-Ford 负环检测 + Floyd 全源最短路，全程整数 / 精确分数运算）
- 前端：原生 HTML / CSS / JavaScript，无构建步骤、无外部 CDN
- 部署：Dockerfile + Docker Compose 一键启动

## 一条命令启动

```bash
docker compose up --build
```

启动后浏览器访问：

```
http://localhost:8000
```

端口：**8000**（宿主机 8000 → 容器 8000，可在 `docker-compose.yml` 的 `ports` 中修改）。

停止：`Ctrl+C`；后台运行：`docker compose up --build -d`；停止并移除：`docker compose down`。

## 不使用 Docker 的本地运行方式

```bash
pip install -r requirements.txt
uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

访问 http://localhost:8000 。

## 使用说明

1. **基准点**：录入 2～30 个唯一名称的基准点（如 A、B、支架端面）。
2. **测量约束**：录入 1～80 条唯一编号的约束，每条指定两个不同的已录入点及整数微米下限、上限（下限 ≤ 上限），含义为

   ```
   终点坐标 − 起点坐标 ∈ [下限, 上限]（闭区间）
   ```
   支持编辑、删除；编号留空时自动生成 M01、M02…
3. **运行一致性校验**：
   - 一致 → 提示全部约束可以同时成立；
   - 矛盾 → 列出一条负权闭环：逐段标明测量编号、**正向/逆向**、**采用的上限或下限**、各段权重，并给出闭环权重和（< 0 即矛盾）。矛盾时按规则**不输出间隙结果**。
4. **间隙查询**：选择起点、终点并填写目标合格区间：
   - 两点在约束图中**未连通** → 标记**无界**，不判合格；
   - 已连通 → 给出由所有约束推得的精确最紧区间 `[L, U]`，并与目标区间比较：
     - **全落入**（最紧区间 ⊆ 目标区间）→ 合格；
     - **仅相交**（有交集但不全落入）→ 待复核；
     - **不相交** → 超差。
5. **示例**：右上角下拉框可一键载入十五套数据，自动运行校验（及查询/精简/预算/拟合/补测窗口/垫片选配/改动影响/最小撤回/复核排程/精度归因/缺失合格概率/极值共现工况）：
   - 示例 1：线性尺寸链（合格）；
   - 示例 2：负权闭环（尺寸矛盾）；
   - 示例 3：未连通与待复核；
   - 示例 4：测量清单精简（含冗余测量，自动生成精简预览）；
   - 示例 5：容差预算（矛盾可修复，自动计算最小预算）；
   - 示例 6：锁定测量矛盾（不可修复）；
   - 示例 7：名义坐标拟合（自动计算拟合方案）；
   - 示例 8：补测读数窗口（自动计算可用读数区间）；
   - 示例 9：垫片组合选配（自动计算最低成本且字典序最小的方案）；
   - 示例 10：尺寸链改动影响（自动保存基线并与编辑稿比较）；
   - 示例 11：矛盾测量最小撤回（自动计算最小撤回预览）；
   - 示例 12：测量复核排程（自动计算最小预期耗时的复核顺序）；
   - 示例 13：目标间隙精度归因（自动计算 Shapley 分摊排名）；
   - 示例 14：测量缺失合格概率（自动按缺失组合精确求和）；
   - 示例 15：极值共现工况（极值冲突，自动计算最多共现子集与工况坐标）。
6. **测量清单精简**（仅对一致清单）：在「⑥ 测量清单精简」点击**生成精简预览**：
   - **判定规则**：按约束录入顺序**逐条试删**。每试一条，都从**当前保留集合**重算**全部有序点对**的最紧上下界；只有当**每一对**的界值与**无界状态**都与**原清单**完全相同，才真正删去该条；后续判断一律基于已删结果（贪心、与录入顺序有关）。
   - **输出**：返回**保留编号**与**可删编号**；并为每条保留约束给出“若再删它”时，按**基准点录入顺序**找到的**首个变化点对**，以及该点对的**删前界 / 删后界**（区分“界值放松”与“变为无界”）。最终保留集合**不可再删**。
   - **矛盾输入**：只显示现有负权闭环证据，**不提供精简清单**。
   - **预览与确认**：页面先给出预览；点击**确认移除**后才把可删项从编辑表删除并重新校验。任何录入变化（增删改基准点/约束、载入示例等）都会让旧预览立即失效。

   例如 A、B、C 三点录入以下 4 条：

   | 编号 | 段 | 区间 [下, 上] μm |
   | --- | --- | --- |
   | M01 | A→B | [10, 20] |
   | M02 | B→C | [10, 20] |
   | M03 | A→C | [20, 40] |
   | M04 | A→B | [5, 25] |

   M03 的区间恰好等于 M01+M02 推出的 A→C 最紧界 [20, 40]，M04 被 M01 完全支配，二者可删；保留 M01、M02 后所有点对界不变。再删 M01 的首个变化点对为 A→B（[10, 20] → 无界），再删 M02 的首个变化点对为 A→C（[20, 40] → 无界），故 M01、M02 均必须保留，精简结果不可再删。
7. **测量容差预算**：在「⑦ 测量容差预算」按测量编号为每条约束设置整数步长（**0～1000，默认 1**；**0 表示锁定**，区间不随预算放宽），点击**计算最小预算**：
   - **规则**：以同一非负整数 k 把每条区间 `[下限, 上限]` 放宽为 `[下限−k×步长, 上限+k×步长]`，求使整张清单**首次一致**的最小 k；未设置步长的编号按 1 处理。
   - **原清单已一致** → 返回 **k = 0**；
   - **锁定测量自身矛盾**（步长 0 的测量之间已存在负权闭环）→ 任何 k 都无法修复，返回**不可修复**及该负环；
   - **k > 0** → 返回 **k−1 下的负权闭环**（再小一步仍矛盾的证据）与 **k 下每条测量的调整后区间**（计算值允许超出 ±10⁹ 的录入范围）。
   - 任何录入或步长变化都会立即清除旧的预算结果。

   例如 A、B、C 三点录入 M01：A→B [10, 20]、M02：B→C [30, 40]、M03：A→C [69, 69]（示例 5）。原清单矛盾：A→B→C 至多为 60，与 M03 的 69 冲突（负环 20+40−69 = −9）。设 M03 锁定（步长 0）、其余步长 1，则 k = 4 时闭环权重和为 24+44−69 = −1 仍矛盾，k = 5 时首次一致：M01 放宽为 [5, 25]、M02 放宽为 [25, 45]、M03 保持 [69, 69]，最小预算 k = 5。
8. **名义坐标拟合**：在「⑧ 名义坐标拟合」为每个基准点录入整数微米**名义坐标**（默认 0），点击**计算拟合方案**：
   - **规则**：**首个基准点的实际坐标固定为 0**；在满足全部测量的**整数**坐标方案中，先最小化最大绝对偏差 **D = max |实际坐标 − 名义坐标|**，再在所有达到最小 D 的方案中按基准点录入顺序取**坐标向量字典序最小**者。
   - **输出**：返回 D 与每个基准点的实际坐标、**有符号偏差（实际 − 名义）**；计算结果允许超出 ±10⁹ 的录入范围。
   - **名义坐标校验**：接口要求 `nominals` 映射**恰好覆盖全部点名**（缺点名或含未录入点名均返回 400），值须为 ±10⁹ 内的整数。
   - **矛盾输入**：只显示现有负权闭环证据，**不给出拟合方案**。
   - 基准点、测量或名义值的任何变化都会立即清除旧的拟合结果。

   例如 A、B、C 三点录入 M01：A→B [10, 20]、M02：B→C [10, 20]、M03：A→C [35, 35]（示例 7），名义坐标 A=0、B=18、C=30。M03 迫使 C = 35，其偏差 +5 不可避免，故最小 D = 5；此时 B 的可行区间为 [15, 20]，虽然 x_B = 18 时 B 自身偏差最小（0），但字典序规则取最小可行值 x_B = 15（偏差 −3，仍满足 |−3| ≤ D）。拟合结果：A = 0、B = 15、C = 35，D = 5，偏差依次为 0、−3、+5。
9. **补测读数窗口**（仅对一致清单）：在「⑨ 补测读数窗口」选择**拟补测的两个不同基准点**（视为在其间补一条精确测量 `[r, r]`），再选择**目标点对**并填写整数微米**合格区间**，点击**计算补测读数窗口**：
   - **规则**：在 r ∈ [−10⁹, 10⁹] 的全部整数中，找出满足以下两条的读数：
     1. 把 `[r, r]` 作为一条新测量加入后，**整张清单仍一致**（无负权闭环）；
     2. 目标点对间隙的**最紧界有界**，且该最紧闭区间**完全落入**合格区间（与间隙查询的“合格”同一标准）。

     结果按起点升序返回全部**不可再扩展（极大）、互不相邻**（相邻区间之间至少隔开 1 个整数）的整数闭区间；算法只做一次全源最短路再取区间交并，**不逐一枚举读数**。
   - **无窗口**：没有任何整数读数满足条件时明确显示**无可用补测读数**（如目标点对在任何补测下都无法连通、或合格区间过严）。
   - **矛盾输入**：只显示现有负权闭环证据，**不提供补测窗口**。
   - 基准点、测量、补测点对或目标条件（点对、合格区间）的任何变化都会立即清除旧窗口结果。

   例如 A、B、C 三点录入 M01：A→B [10, 20]、M02：B→C [10, 20]（示例 8）。拟在 A→B 间补测精确读数 r，要求目标 A→C 完全落入 [24, 36] μm。补测后 A→C 的最紧区间为 [r+10, r+20]，完全落入要求 r+10 ≥ 24 且 r+20 ≤ 36，即 **r ∈ [14, 16]**；同时 r 本身必须落在原 A→B 最紧界 [10, 20] 内（否则补测与 M01 矛盾）。故窗口为单个整数闭区间 `[14, 16]`，三个读数 14、15、16 均可；r=13 时下界 23 < 24、r=17 时上界 37 > 36，落在窗口之外。合格区间改严为 [25, 35] 时只剩 r=15；改宽为 [20, 40] 时窗口为 [10, 20]（再向两侧扩展即与 M01 冲突，故已不可再扩展）。
10. **垫片组合选配**（仅对一致清单）：在「⑩ 垫片组合选配」选择**目标点对**、填写整数微米**合格区间**，并录入 **1～10 个有序安装位**：
    - 每位方向为 **+1 或 −1**，提供 **1～6 个**选项，每个选项给出整数**厚度（0～10⁶ μm）**与整数**成本（0～1000）**；
    - 点击**计算垫片选配方案**后，每位**恰选一个**选项，其有符号厚度之和（净补偿量）**只把目标点对的原最紧区间整体平移**，不修改任何测量；要求**平移后的整个区间**完全落入合格区间；
    - **优化目标**：先使所选选项的**总成本最低**；总成本相同时，按安装位顺序取**从 1 开始的选项序号向量字典序最小**者（即先尽量选第 1 位上序号最小的选项，再看第 2 位……）；
    - **返回**：每位选中的选项（序号、厚度、方向、有符号厚度、成本）、**净补偿量**、**调整后区间**与**总成本**；算法按“有符号厚度和 → (最低成本, 最小字典序秩)”做分层动态规划，同和状态合并、按后缀可达区间剪枝，每层按预计可达状态数在稀疏字典与稠密数组间自适应选择表示（稀疏可达和绝不按整个整数跨度开数组），**不逐一枚举** 6¹⁰ 种组合；
    - **原清单矛盾**时只显示现有负权闭环证据，**不给出选配方案**；
    - **目标间隙无界**（两点未连通）时说明垫片只能整体平移、不能使无界区间变界，**无法选配**；合格区间容不下原最紧区间（宽度不足）或没有任何组合能达到所需净补偿量时，明确提示**垫片选配无解**；
    - 基准点、测量、目标条件（点对、合格区间）或任一安装位/选项（增删、方向、厚度、成本）的变化都会立即清除旧的选配结果。

    例如 A、B、C 三点录入 M01：A→B [10, 20]、M02：B→C [10, 20]（示例 9），目标 A→C 合格区间为 [24, 44] μm。原最紧区间为 [20, 40] μm，整体平移后要求 20+S ≥ 24 且 40+S ≤ 44，故所需净补偿量**恰为 S = 4** μm。录入两个安装位：第 1 位方向 +1，选项为 10 μm/成本 5、5 μm/成本 1、8 μm/成本 3；第 2 位方向 −1，选项为 6 μm/成本 1、1 μm/成本 5、3 μm/成本 2。能达到 S=4 的组合有 (10, 6) 与 (5, 1) 两个，成本均为 6；字典序取**选项序号向量 (1, 1)**（10 μm 正向 + 6 μm 反向），净补偿量 +10−6 = **+4 μm**，调整后区间 **[24, 44] μm** 恰好完全落入合格区间，总成本 **6**。若把合格区间放宽为 [20, 44]（所需 S ∈ [0, 4]），低成本组合 5−3=2（成本 1+2=3，序号向量 (2, 3)）成本更低，即改选该组合——说明结论随条件重新优化。

    **边界场景（稀疏大跨度）**：原间隙 [0, 0]、合格区间 [0, 10⁷]，10 个安装位方向均为 +1，每位 6 个选项厚度依次为 0 / 2×10⁵ / 4×10⁵ / 6×10⁵ / 8×10⁵ / 10⁶ μm、成本均为 0。所需净补偿量区间为 [0, 10⁷]，全部组合成本相同（0），字典序最小即每位都选**第 1 个选项**（厚度 0）：净补偿量 **0**、调整后区间 **[0, 0]**、总成本 **0**。此时候选和跨度达 10⁷，但可达有符号和每层仅数十个（都是 2×10⁵ 的倍数）；求解按实际状态数分配内存（稀疏字典），在 256 MiB 内存上限内即可得出结果，不会按整个整数跨度开出 10⁷ 量级的数组。
11. **尺寸链改动影响**：在「⑪ 尺寸链改动影响」点击**保存当前为基线**，把当前基准点与测量清单存为独立基线（可随时重新保存覆盖、或清除基线），随后继续编辑测量；点击**比较改动影响**即把基线与当前编辑稿一起提交比较：
    - **前提**：两版的**基准点名称与顺序必须完全相同**（测量可任意增删改），否则返回 400；基线与编辑稿**分别沿用**与「一致性校验」相同的录入校验（出错时消息带“基线：/编辑稿：”前缀）。
    - **两版均一致** → 按基准点录入顺序逐**有序异点对**比较最紧上下界与无界状态，仅返回**发生变化**的点对（列出前后界，无界为 `null`），并判定变化类别：
      - 新区间**真包含于**旧区间 → **收紧**；
      - 旧区间真包含于新区间 → **放宽**；
      - 两区间**互不包含** → **混合**；
      - 旧无界、新有界 → **变为有界**；旧有界、新无界 → **变为无界**（优先于收紧/放宽判定）。
    - **任一版矛盾** → 返回各矛盾版本各自的负权闭环，**不生成点对差异**。
    - 基线或编辑稿的任何变化（增删改基准点/约束、重新保存或清除基线、载入示例等）都会立即清除旧报告。

    例如 A、B、C 三点，基线为 M01：A→B [10, 20]、M02：B→C [10, 20]、M03：A→C [20, 40]；编辑稿改为 M01：A→B [12, 18]（改）、M02：B→C [5, 25]（改）、M04：A→C [24, 36]（M03 删除、M04 新增）（示例 10）。基线最紧界为 A→B [10, 20]、B→C [10, 20]、A→C [20, 40]（M03 恰与 M01+M02 一致）；编辑稿最紧界为 A→B [12, 18]、A→C [24, 36]、B→C **[6, 24]**（注意不是 M02 的 [5, 25]：M01 与 M04 联合把 B→C 进一步收紧）。报告共 6 个有序点对：A→B、A→C、B→A、C→A 判**收紧**，B→C、C→B 判**放宽**。
12. **矛盾测量最小撤回**：在「⑫ 矛盾测量最小撤回」把每条测量标记为**可撤回**或**锁定**（缺省锁定，**可撤回至多 16 条**），点击**计算最小撤回预览**：
    - **规则**：只允许删除**可撤回**测量，求使剩余清单一致的**最少删除条数**；并列时按原录入顺序取**删除序号列表字典序最小**者（删除序号为从 1 开始的录入位置）。求解由负环引导搜索——每次在当前图中找一条负权闭环，只沿环上的可撤回编号分支，并用“可撤回编号两两不交的负环打包”作下界剪枝，**不遍历全部删除子集**。
    - **原清单一致** → 返回**空撤回集**（删除 0 条）；
    - **锁定测量自身矛盾**（未标记可撤回的测量之间已存在负权闭环）→ 任何撤回都无法修复，返回**不可修复**及**锁定部分的负权闭环**（并附原清单的负环）；
    - **可修复** → 预览展示**原负环**、**撤回编号**（含删除序号）与**剩余清单**；点击**确认撤回**后才把撤回项从编辑表删除并重新校验。
    - 基准点、测量或可撤回标记的任何变化（增删改基准点/约束、切换标记、载入示例等）都会让旧预览立即失效。

    例如 A、B、C 三点录入 M01：A→B [10, 20]、M02：B→C [30, 40]、M03：A→C [69, 69]、M04：C→A [−60, −50]（示例 11）。M01+M02 推出 A→C 至多为 60，与 M03 的 69 冲突（负环 20+40−69 = −9）；M04 又要求 A→C ∈ [50, 60]，与 M03 单独构成负环（60−69 = −9）。标记 M01、M02、M03 可撤回、M04 锁定：只删 M01 或只删 M02 都仍留下 M03 与 M04 的矛盾，唯有删去 M03 能同时消除两条负环，故最少撤回 **1 条**（M03，删除序号 [3]），剩余 M01、M02、M04 一致（A→C 最紧界 [50, 60]）。并列规则的示例：A、B 两点录入三条两两冲突的测量 M01：A→B [0, 5]、M02：A→B [10, 20]、M03：A→B [30, 40] 且全部可撤回，最少须撤回 2 条，候选 {M01, M02}、{M01, M03}、{M02, M03} 中按删除序号列表字典序最小取 **[1, 2]**（撤回 M01、M02，保留 M03）。
13. **测量复核排程**：在「⑬ 测量复核排程」从当前清单**选取 1～16 条测量**，为每条设置：
    - **复核耗时**：1～1000 的整数；
    - **独立不合格概率**：0～999 的整数（单位 ‰；合格概率 = (1000−p)/1000，各条相互独立）；
    - **必须先复核的测量编号**：逗号分隔；**只能引用所选测量**（引用未选取的编号报错），不得重复、不得依赖自身，**依赖成环时报错**（返回环上的编号）。

    点击**计算复核排程**：复核按某一完整顺序逐条进行，**遇到首条不合格即停止**（后续条目不执行）。求**满足全部先决依赖且预期总耗时最小**的完整顺序；并列时按**原录入位置的序号向量**（顺序中各条在测量清单里从 1 开始的录入位置）取字典序最小者。概率与期望值全程用**精确分数**计算，求解为 2ⁿ 状态的子集动态规划（n ≤ 16），**不枚举全部排列**。
    - **返回**：完整顺序、每步**执行概率**（此前各项均合格的概率，既约分数及其有限十进制展开）、**预期总耗时**（既约分数及其有限十进制展开）与录入位置序号向量；
    - 测量（增删改）或排程参数（选取、耗时、概率、依赖）的任何变化都会立即清除旧的排程结果。

    例如 A、B、C 三点录入 M01：A→B [10, 20]、M02：B→C [10, 20]、M03：A→C [20, 40]、M04：A→B [5, 25]（示例 12），选取全部 4 条并设置：M01 耗时 8、不合格 0‰；M02 耗时 5、不合格 200‰；M03 耗时 3、不合格 100‰、须先复核 M02；M04 耗时 4、不合格 400‰、须先复核 M01。若不考虑依赖，按“耗时 ÷ 不合格概率”贪心应把永不不合格的 M01 排最后，但 M04 的依赖迫使 M01 提前。满足两条依赖的最优顺序有两个：M02→M01→M04→M03 与 M02→M03→M01→M04，预期总耗时都是 5 + 0.8×8 + 0.8×4 + 0.48×3 = **401/25 = 16.04**；按录入位置序号向量字典序取 **[2, 1, 4, 3]**（即 M02→M01→M04→M03）。各步执行概率依次为 1、4/5 = 0.8、4/5 = 0.8、12/25 = 0.48。
14. **目标间隙精度归因**（仅对一致清单）：在「⑭ 目标间隙精度归因」选择**目标点对**，并从当前清单**选取 1～10 条待评估测量**（未选取的测量固定为**底座**），点击**计算精度归因**：
    - **规则**：对底座加每个待评估子集 S 求目标间隙的**最紧区间宽度** W(S)（最紧区间 `[L, U]` 的宽度即 `U−L`；底座须已使目标点对有界，否则宽度无从定义）。按 **Shapley 权重** `|S|!(n−|S|−1)!/n!`（n 为待评估条数）把宽度缩减 `W(S)−W(S∪{i})` 分摊给测量 i，即

      ```
      贡献_i = Σ_{S ⊆ N\{i}}  |S|!(n−|S|−1)!/n! · ( W(S) − W(S∪{i}) )
      ```

      全部贡献之和恰等于**底座宽度 − 全量宽度**（Shapley 效率性），每条贡献非负（加测量只会收紧或保持最紧界）。
    - **返回**：底座宽度 W(∅)、全量宽度 W(N)、宽度差，以及每条待评估测量的**贡献（既约分数，μm）**与**排名**——按贡献降序、并列按原录入顺序（从 1 开始的录入位置）；分母可含 3、7 等因子，不一定有有限十进制展开，页面上的近似小数仅供阅读，精确值以分数为准。求解沿子集递归树增量计算（每个子集对应一个节点，共 2ⁿ 个节点），**不枚举全部排列**。
    - **矛盾输入**：只显示现有负权闭环证据，**不提供归因结果**。
    - **不可归因**：底座（未选取的测量）不能给出目标间隙的**有界**最紧区间（目标点对在底座约束图中不连通）时明确提示**不可归因**——例如把全部测量都选为待评估时底座为空，必然不可归因。
    - 基准点、测量、选取或目标点对的任何变化都会立即清除旧的归因结果。

    例如 A、B、C 三点录入 M01：A→B [10, 20]、M02：B→C [10, 20]、M03：A→C [25, 35]、M04：A→C [0, 100]（示例 13），目标 A→C，待评估 M01、M02、M03（M04 留作底座）。底座只有 M04 时 A→C ∈ [0, 100]，宽度 **100**；全量时最紧区间为 [25, 35]，宽度 **10**，宽度差 90。各子集宽度：W(∅)=100，W({M01})=W({M02})=100（B→C 或 A→B 断开，仍只剩 M04），W({M03})=10，W({M01,M02})=20（链接出 [20, 40]），W({M01,M03})=W({M02,M03})=10，W({M01,M02,M03})=10。按 Shapley 权重 1/3、1/6、1/6、1/3 分摊：M03 贡献 190/3 ≈ 63.33（它独自把宽度从 100 收到 10），M01、M02 各贡献 40/3 ≈ 13.33（只有合起来才有用，均分协同收益），三者之和 190/3+40/3+40/3 = 90 恰等于宽度差。排名：M03 第 1，M01、M02 并列按录入顺序分列第 2、3。
15. **测量缺失合格概率**（仅对一致清单）：在「⑮ 测量缺失合格概率」选择**目标点对**、填写整数微米**合格区间**，并从当前清单**选取 1～12 条可能缺失的测量**，为每条填写其**独立缺失概率**（0～1000 的整数，单位 ‰；缺失与有效概率分别为 p/1000 与 (1000−p)/1000，各条相互独立）。**未选取的测量始终有效**。
    - **规则**：完整清单须一致；**矛盾时只返回现有负权闭环，不计算概率**。一致时枚举全部 2ⁿ 种缺失组合（n ≤ 12），每种组合把对应测量从约束图中移除后重算目标点对间隙的最紧上/下界；**仅当目标有界（双向连通）且整个最紧闭区间完全落入合格区间时**（与间隙查询的“合格”同一标准）该组合才计为**通过**，无界或未完全落入均计为**未通过**。组合概率为各条“缺失 p_i/有效 (1000−p_i)”千分分子之积（公分母 1000ⁿ），通过、未通过两类分别**精确求和**并约分为**既约分数**返回，二者之和恰为 1（分母只含因子 2、5，必有有限十进制展开，页面同时给出百分数）。
    - **确定事件**：缺失概率填 **0‰** 表示该测量必然有效（缺失分支权重为 0），填 **1000‰** 表示必然缺失（有效分支权重为 0）；结构上仍枚举全部 2ⁿ 种组合（返回通过/未通过的组合数），零概率组合不贡献权重。
    - **返回**：完整清单（无缺失）下目标的最紧界与有界状态、缺失组合总数与通过/未通过组合数、每条所选测量的缺失/有效概率，以及通过概率、未通过概率（既约分数的分子/分母字符串与有限十进制）。目标在某些组合下无界（点对因测量移除而断开）时这些组合计为未通过。
    - **增量更新**：底座（未选测量）只做一次全点 Floyd 并把距离汇总到“目标点对＋各所选测量端点”的终端图；所选测量沿**子集递归树**逐条以两条边增量加入（单条新边 u→v 的更新 `d′[i][j] = min(d[i][j], d[i][u]+w+d[v][j])`，不进入缺失集的分支共享父矩阵），**不为每种组合重跑全点最短路**，共 2ⁿ 个叶节点。
    - 基准点、测量、目标条件（点对、合格区间）或任一缺失率的任何变化都会**立即撤下旧结果**。

    例如 A、B、C 三点录入 M01：A→B [10, 20]、M02：B→C [10, 20]、M03：A→C [20, 40]（示例 14），目标 A→C、合格区间 [20, 40] μm，选取三条测量，缺失概率依次为 **100‰、200‰、500‰**（有效概率 900‰、800‰、500‰）。8 种缺失组合逐一判定：

      | 缺失组合 | 在场测量推出的 A→C 最紧界 | 判定 | 组合概率 |
      | --- | --- | --- | --- |
      | ∅（无缺失） | [20, 40] | 通过 | 0.9·0.8·0.5 = 0.36 |
      | {M01} | M02+M03：[20, 40] | 通过 | 0.1·0.8·0.5 = 0.04 |
      | {M02} | M01+M03：[20, 40] | 通过 | 0.9·0.2·0.5 = 0.09 |
      | {M03} | M01+M02：[20, 40] | 通过 | 0.9·0.8·0.5 = 0.36 |
      | {M01, M02} | M03：[20, 40] | 通过 | 0.1·0.2·0.5 = 0.01 |
      | {M01, M03} | 只剩 M02：无界 | 未通过 | 0.1·0.8·0.5 = 0.04 |
      | {M02, M03} | 只剩 M01：无界 | 未通过 | 0.9·0.2·0.5 = 0.09 |
      | {M01, M02, M03} | 无任何测量：无界 | 未通过 | 0.1·0.2·0.5 = 0.01 |

      8 种结构组合中 5 种通过、3 种未通过。**通过概率** = 0.36+0.04+0.09+0.36+0.01 = **0.86 = 43/50 = 86%**；**未通过概率** = 0.04+0.09+0.01 = **0.14 = 7/50 = 14%**（系统在 1000³ 公分母上精确求和后约分）。若把 M03 的缺失率改为 **1000‰（必然缺失）**，则通过要求 M01、M02 同时在场（二者链接出的 [20, 40] 恰合格），通过概率 0.9·0.8 = **0.72**；改为 **0‰（M03 必然有效）** 时任何组合都有 M03 保证 [20, 40]，通过概率 **1**。
16. **极值共现工况**（仅对一致清单）：在「⑯ 极值共现工况」按顺序录入 **1～10 个目标**，每项选择两个不同基准点构成的**有序间隙**及**界别**（最紧下界 / 最紧上界）；**同一有序点对、同一界别不得重复**（同一点对的反向或不同界别允许并存）。点击**计算极值共现工况**：
    - **规则**：对完整清单求每个目标有序间隙的**最紧整数界**（上界 dist(起点,终点)、下界 −dist(终点,起点)），把“**达到该界**”作为等式条件 `x(终点) − x(起点) = 界值` 叠加到原测量上；在所有能**同时成立**（与原测量合起来仍无负权闭环）的目标子集中取**目标数最多**者，并列时取**输入序号列表字典序最小**者。

    - **目标界无界**：任一目标的两个基准点在原测量图中不连通（对应界别推不出有限界值）时，**报明目标序号、不生成工况**；
    - **原清单矛盾**：只显示现有负权闭环证据，**不生成工况**；
    - 基准点、测量或任一目标（点对、界别、增删、顺序）的任何变化都会立即清除旧工况。

    **极值冲突示例**：A、B、C 三点录入 M01：A→B [10, 20]、M02：B→C [10, 20]（示例 15），依次录入三个目标：① A→C 最紧上界、② A→B 最紧下界、③ B→C 最紧下界。完整清单下各界值为 ① 40、② 10、③ 10 μm。目标①要求 x_C − x_A = 40，即两段必须同时取上限 20；目标②、③分别要求对应段取下限 10，故①与②、①与③均冲突，而②与③可以并存。最多 2 个目标同时达到极值：候选 {①,②}、{①,③} 均不可行（分别迫使另一段超出上限 20），{②,③} 可行，故入选序列为 **[2, 3]**、未入选为 **[1]**；工况坐标 A = 0（分量零点）、B = 10、C = 20，此时 A→B = 10、B→C = 10 双双达到各自最紧下界，A→C = 20 ∈ [20, 40] 仍满足全部原测量。若改录目标为 ① A→C 最紧下界（20）、② A→B 最紧下界（10）、③ B→C 最紧下界（10），三者不再冲突（x = (0, 10, 20) 同时达到），入选即全部 3 个目标。

页面数据会自动保存在浏览器 localStorage 中，刷新不丢失。

## 建模原理

对约束 `low ≤ x_to − x_from ≤ high` 建两条有向边（差分约束标准形式 `x_v − x_u ≤ w`）：

- `from → to`，权重 `high`（正向，采用上限）；
- `to → from`，权重 `-low`（逆向，采用下限）。

- 系统一致 ⇔ 图中**无负环**（Bellman-Ford）；负环即一条“加权后总长为负”的闭环，逐段不等式相加会得到形如 `0 ≤ 负数` 的矛盾。
- 一致时，间隙 `x_q − x_p` 的最紧上界是 `dist(p,q)`、最紧下界是 `-dist(q,p)`（Floyd 全源最短路）；任一不可达即两点未连通、间隙无界。
- 清单精简：删去一条测量即删去它贡献的两条边。对当前保留集合重算 Floyd，若全矩阵（每个 `dist(p,q)` 的值与不可达状态）与原清单逐元素相同，则该测量不影响任何有序点对的推断，可删；按录入顺序贪心、基于已删结果逐条试删。最后对保留集合中每条测量再试删一次，取与当前矩阵最早出现差异（按基准点录入顺序枚举点对）的点对作为其必要性见证。
- 容差预算：预算 k 把每条区间放宽为 `[low−k·s, high+k·s]`（s 为该测量步长），对应边权变为 `high+k·s` 与 `−low+k·s`，随 k 单调不减，故一致性关于 k 单调，二分即得首次一致的最小 k。步长 0（锁定）的边权不随 k 变化：若仅由锁定测量构成的子图已含负环，则该矛盾对任意 k 成立，判定不可修复。二分上界取 `−n·w_min`（n 为点数、`w_min` 为 k=0 时的最小边权）：任一简单环至多 n 条边，含非锁定边的环步长和 ≥ 1，超过该上界后所有环权重必非负。
- 名义坐标拟合：增设锚点代表绝对零位，用两条 0 权边令首点坐标等于锚点（即固定为 0）；`|x_i − 名义_i| ≤ D` 对每条名义界化作一对锚点界边。给定 D 时“存在满足全部测量且偏差不超过 D 的整数方案”⇔ 该差分约束系统无负环，且可行性关于 D 单调，故二分求最小 D（上界取自任意一组可行势对应的偏差）。随后按基准点录入顺序逐点把 `x_i` 固定为当前最紧下界 `−dist(i, 锚点)`：差分约束对单变量的投影是区间，固定区间内任一整数值都保持系统可行，故该贪心恰好给出最小 D 下字典序最小的坐标向量。全程整数运算，计算结果不受 ±10⁹ 录入范围限制。
- 补测读数窗口：精确补测 `[r, r]`（a→b）只新增两条边 `a→b` 权 r、`b→a` 权 −r。设原清单（无负环）Floyd 全源最短路为 dist，加入新边后的最紧上界（路径至多使用一次新边：无负环时含环路径去环后不更长；各项不可达视为 +∞）：

  ```
  dist′[u][v] = min( dist[u][v],
                     dist[u][a] + r + dist[b][v]  （经 a→b 边）,
                     dist[u][b] − r + dist[a][v] )（经 b→a 边）
  ```

  - 一致性：新出现的负环必含新边。含 `a→b` 边的环 ⇔ `dist[b][a] + r < 0` ⇔ `r < −dist[b][a]`（下界 L，不可达则无此约束）；含 `b→a` 边的环 ⇔ `dist[a][b] − r < 0` ⇔ `r > dist[a][b]`（上界 U，不可达则无此约束）。故使清单仍一致的 r 恰为整数区间 `[L, U]`，再与 `[−10⁹, 10⁹]` 取交。
  - 有界且合格：目标上界要求 `dist′[p][q] ≤ 目标上限`、目标下界要求 `−dist′[q][p] ≥ 目标下限` ⇔ `dist′[q][p] ≤ −目标下限`。对任一界 `dist′[u][v] ≤ B`，记 `α = dist[u][a]+dist[b][v]`、`β = dist[u][b]+dist[a][v]`（缺项为 +∞）；原界已 ≤ B 时全部 r 可行，否则 `min(α+r, β−r) ≤ B` 的**补集**是 `r ≥ B−α+1` 与 `r ≤ β−B−1` 两个半直线的**交集**——单个闭区间（α、β 均缺项即该界永远无界，禁用全部 r）。两个目标界各产生至多一个禁用闭区间/半直线，与一致区间取交、合并相交或相邻段后取补集，即全部极大、互不相邻的合格整数窗口。整体 O(n³)，与读数范围大小无关，故不逐一枚举 r。
- 垫片组合选配：垫片只是装配补偿，不新增或放宽任何测量。目标点对 p→q 的原最紧间隙是闭区间 `[L, U] = [−dist[q][p], dist[p][q]]`；每个安装位 i 选一个选项，净补偿量 `S = Σ d_i·t_i`（`d_i ∈ {+1,−1}` 为该位方向、`t_i` 为所选厚度）。整体平移后区间为 `[L+S, U+S]`，其完全落入合格区间 `[T₀, T₁]` 当且仅当 `T₀−L ≤ S ≤ T₁−U`（所需净补偿量区间）。若 `T₀−L > T₁−U`（等价于合格区间宽度小于原区间宽度 `U−L`）则任何平移都不可行；否则求满足该整数区间约束的选择向量。
  - **分层动态规划**：按安装位顺序逐层推进，状态键为前缀有符号厚度和 s，状态值为 `(最低成本, 最小字典序秩)`，同一和只保留成本最低、成本相同时秩最小的一个。秩把第 t 位选项序号 j（0 起）编码为 `j·6^(k−1−t)`（每位至多 6 个选项），最终秩恰好是选项序号向量的 6 进制表示；中间层同和合并之所以安全，是因为后缀可选范围只取决于当前和、与历史选择无关，而任意两条前 t 位不同路径的秩差至少 `6^(k−t)`，严格大于后 k−t 位的最大增量 `6^(k−t)−1`，故“成本相同取秩小”与最终向量字典序最小完全一致。
  - **剪枝与表示自适应**：预处理每位前缀/后缀有符号和的可达极值，前缀和 s 经后缀只能覆盖 `[s+后缀最小, s+后缀最大]`；该区间与所需区间不相交的状态立即剪除。每层再按“预计可达状态数（上界 min(保留跨度, 当前状态数×本层选项数)）占保留跨度的比例”重新选择表示：稀疏时用哈希表 `{和: 编码}`，只存实际可达的和，内存与状态数成正比——稀疏大跨度（如厚度都是 2×10⁵ 的倍数、跨度 10⁷ 而可达和仅数十个）绝不按整个整数跨度开数组；跨度 ≤ 2×10⁶ 且预计状态足够密（≥ 跨度的 1/8）时改用“偏移 + INF 哨兵”的区间数组，下标即和，省去哈希开销。状态值把 (最低成本, 最小字典序秩) 打包为一个整数 `成本·6^k + 秩`，整数大小序即该二元序。状态数上界是可达有符号和的个数（≤ 2.1×10⁷ 量级）而非组合数 `∏选项数 ≤ 6¹⁰`，故不逐一枚举全部组合。
- 尺寸链改动影响：两版测量清单共享同一组基准点（名称与顺序相同），各自建边判负环；任一版矛盾即只返回各矛盾版本的负环，不生成点对差异。均一致时对两版分别求 Floyd 全源最短路，按基准点录入顺序逐有序异点对 (p, q) 比较最紧区间 `[−dist(q,p), dist(p,q)]` 的界值与无界状态，仅报告不同的点对；变化类别按区间包含关系判定：把无界侧视为 ±∞ 后，新区间 ⊆ 旧区间（且不同）即收紧、旧区间 ⊆ 新区间（且不同）即放宽、互不包含即混合；有界↔无界的跃迁（变为有界 / 变为无界）优先于包含关系单独标出。
- 矛盾测量最小撤回：删除集合 D 可行 ⇔ 原图的每条负权闭环都至少含 D 中一条测量（删边只会消除闭环），故“使剩余清单一致的最少删除”即**全部负环的最小碰集**。搜索不枚举删除子集：每次在当前图中找一条负环，只需删除环上某一条可撤回测量即可打破它，于是只沿环上的可撤回编号分支（最小碰集的标准回溯）；并用“可撤回编号两两不交的负环打包”作下界剪枝——打包出的每个环都需要一次互不相同的删除，已删条数 + 打包下界超过已知最优即剪枝。删除全部可撤回测量后只剩锁定测量（已预先验证一致），故只要锁定部分一致就必有解；锁定测量自身含负环时，该矛盾与任何可撤回删除无关，直接判不可修复并返回锁定部分的负环。并列的最少删除方案按删除序号（从 1 开始的录入位置）列表字典序取最小。可撤回测量至多 16 条，搜索规模受环分支与下界剪枝双重限制。
- 测量复核排程：复核按完整顺序 π 逐条进行、遇首条不合格即停止，故第 k 条只在“此前各项均合格”时才执行，预期总耗时 `E(π) = Σ_k t_{π(k)} · ∏_{j<k} ( s_{π(j)} / 1000 )`（t 为复核耗时，s = 1000 − 不合格概率‰ 为合格概率的千分分子，s ≥ 1）。求解用**子集动态规划**而非枚举排列：令 `H(R) = 1000^|R| ·`（在“此前各项均合格”条件下处理剩余集合 R 的最小预期耗时），则 `H(∅) = 0`，且 `H(R) = min_{i ∈ R, deps(i) ∩ R = ∅}  t_i·1000^|R| + s_i·H(R \ {i})`——i 可作为 R 中下一条当且仅当其全部先决测量已不在 R 中（依赖无环保证每个非空子集都有可选项，成环在录入校验时即报错）。同一 R 的各候选分母同为 `1000^|R|`，故**整数比较即精确比较**；同值候选取**录入位置最小**者（首元素即决定序号向量字典序，后缀递归同理），还原选择即得全局字典序最小顺序。状态数 2ⁿ（n ≤ 16）、每状态至多 n 个转移，不枚举 n! 个排列。每步执行概率与预期总耗时以既约分数返回；分母均为 1000 的幂的因子（只含因子 2 与 5），故十进制展开必有限，一并随分数返回。
- 目标间隙精度归因：未选取的测量固定为底座，待评估测量共 n 条（1～10）。目标间隙最紧区间宽度 `W(S) = dist_S[p][q] + dist_S[q][p]`（底座加子集 S 的全源最短路；底座即有界，故所有超集均有界）。每条测量的贡献为 Shapley 值 `φ_i = Σ_{S⊆N\{i}} |S|!(n−|S|−1)!/n! · (W(S) − W(S∪{i}))`——即对“测量 i 加入后宽度缩减量”按随机到达顺序取期望的标准分摊；由 Shapley 效率性，全部贡献之和恰为 `W(∅) − W(N)`（底座宽度 − 全量宽度），且加测量只会收紧最紧界，故各贡献非负。各 `W(S)` 在**终端图**上增量计算而不枚举排列：终端取目标点对与各待评估测量端点（至多 2+2n 个），底座 Floyd 全源最短路把终端间距离汇总为初始边（真实路径按终端分段后不短于对应底座最短路，反向展开亦可达，故终端图距离与原图一致）；随后沿**子集递归树**逐条加入待评估测量，每条化作两条有向边，单条新边 `u→v`（权 w）的最短路更新为 `d'[i][j] = min(d[i][j], d[i][u] + w + d[v][j])`（无负环时任一最短路至多经过新边一次），每边 O(|T|²)；递归树每个节点对应一个子集，共 2ⁿ 个节点，不枚举 n! 个排列。贡献以 `Fraction(Σ |S|!(n−|S|−1)!·ΔW, n!)` 精确计算并约分为既约分数；排名按贡献降序、并列按原录入顺序。
- 测量缺失合格概率：未选取的测量始终有效（底座），可能缺失的测量共 n 条（1～12），各条独立地以概率 `p_i/1000` 缺失、`(1000−p_i)/1000` 有效（0‰/1000‰ 即确定事件）。缺失集合 D 对应的子图＝底座＋`{i ∉ D}` 的所选测量；目标间隙最紧上界 `dist_D[p][q]`、下界 `−dist_D[q][p]`，该组合通过当且仅当两界均可达（有界）且 `目标下限 ≤ −dist_D[q][p]` 与 `dist_D[p][q] ≤ 目标上限` 同时成立（最紧区间整体落入合格区间）。组合权重 `w(D) = ∏_{i∈D} p_i · ∏_{i∉D} (1000−p_i)`，公分母恒为 `1000^n`（`Σ_D w(D) = ∏_i (p_i + (1000−p_i)) = 1000^n`）；通过权重和、未通过权重和分别构造 `Fraction(权重和, 1000^n)` 约分，分母只含因子 2、5，十进制展开必有限。子图最短路与精度归因同样在**终端图**（终端＝目标点对＋各所选测量端点，至多 2+2n 个）上沿子集递归树增量计算：底座 Floyd 只跑一次并汇总为终端初始边；“测量缺失”分支不加入其两条边并与父节点共享同一矩阵（不复制），“测量有效”分支复制矩阵后各做一次 O(|T|²) 的单边增量松弛，故 2ⁿ 个叶节点对应 2ⁿ 种组合却**不为每种组合重跑全点最短路**（复制/松弛总量 O(2ⁿ·|T|²)）；零权重分支（0‰ 缺失或 0‰ 有效）也照常遍历，以正确统计结构组合数。删边不可能制造负环，故完整清单一致时所有子图一致，增量松弛公式始终成立。
- 极值共现工况：对完整清单求 Floyd 全源最短路后，每个目标有序间隙 `x_q − x_p` 的最紧上界为 `dist(p,q)`、最紧下界为 `−dist(q,p)`（边权皆整数，故界值皆整数）；“达到该界”即等式 `x_q − x_p = 界值`，化作一对反向等权边（`p→q` 权界值、`q→p` 权负界值）叠加到原测量图上。一个目标子集能由同一组坐标同时达到 ⇔ 叠加对应等式边后的差分约束系统仍无负权闭环。目标至多 10 个，按子集大小从大到小、同大小按输入序号字典序扫描全部子集（至多 2¹⁰ 个，每次判定为一次 Bellman-Ford），首个无负环的子集即目标数最多且输入序号列表字典序最小者。工况坐标取叠加图的可行势（Bellman-Ford 超源构造，整数），再按**原始测量图**的连通分量整体平移，使每个分量最早录入的基准点为零点——分量间无任何约束，分量内整体平移不改变任何坐标差，故平移后仍满足全部原测量与入选等式。任一目标两点在原图中不连通时该侧界无界，报明目标序号后不生成工况。

所有尺寸数字按整数微米精确计算；复核排程的概率与期望值、精度归因的各测量贡献、测量缺失合格概率的通过/未通过概率均以精确分数（既约分数）计算与返回，全程无浮点误差。
